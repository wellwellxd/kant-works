# 純粹理性批判｜Kritik der reinen Vernunft

作者：Immanuel Kant（康德）

本資料夾將逐步建立可閱讀的繁體中文譯本，並以德文原文核對。

## 底本
- B 版（1787，主要翻譯底本）：https://www.gutenberg.org/ebooks/6343
- A 版（1781，對照底本）：https://www.gutenberg.org/ebooks/6342
- 1781 年初版掃描及校對：https://de.wikisource.org/wiki/Critik_der_reinen_Vernunft_(1781)

## 編輯原則
1. 德文原文與繁體中文譯文分開存放，不將英譯本當成原文。
2. 譯文力求準確、通順；重要術語保留德文及必要註解。
3. 區分 A/B 版，不把不同版本混合為單一原文。
4. 逐章完成，翻譯尚未完成的章節不標示為完成。
5. 原典屬公共領域；新譯文需另外決定授權方式。
