# 純粹理性批判｜Kritik der reinen Vernunft

這是一套**繁體中文哲學家教式精讀課程**，不是逐字翻譯或出版專案。學生不懂德文；所有德文引用與術語須先翻成中文，才能作為課程材料。

## 從這裡開始
- [課程總綱](課程/課程總綱.md)：七階段、36課
- [教學與語言規範](課程/教學與語言規範.md)：中文優先、原典引用、論證教學原則
- [第一課｜課程計畫](課程/第01課/第一課計畫.md)：學習目標、原典位置與授課流程
- [第一課｜完整中文教材（手機直接閱讀）](課程/第01課/第一課教材.md)：原典節譯、思想實驗、反駁與理解檢核
- [第一課｜互動 HTML 單頁](課程/第01課/第一課互動版.html)：字體調整、答案揭曉、互動測驗與本機筆記（需下載 HTML 後在瀏覽器開啟；GitHub 檔案頁只顯示原始碼）
- [單課模板](課程/單課模板.md)：後續每堂課的教材格式
- [德文原典來源](原文/SOURCES.md)：1787年B版、1781年A版

## 重要說明
課程以1787年第二版為主，必要時對照1781年第一版。所有引文先提供繁體中文節譯，並標示可核實的原典位置。現有「譯文」目錄為早期初始化遺留，**不代表本專案仍以全書翻譯為目標**。

## 手機閱讀第一課

建議直接開啟[完整中文教材 Markdown](課程/第01課/第一課教材.md)，在 GitHub 手機版就能閱讀，提示可展開。若想使用可輸入筆記、調整字級、作答的互動介面，下載[單檔 HTML](課程/第01課/第一課互動版.html)後在瀏覽器開啟。互動版筆記只在該瀏覽器本機儲存，不自動上傳 GitHub；請自行備份。
