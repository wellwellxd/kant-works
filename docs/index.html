這堂課怎麼進行？

每堂課都以德文原著的可核對段落為基礎，但提供給你的引文先翻成繁體中文。你可以停下來反駁、做筆記，再與我討論。所有課程不要求固定時間內學完。

本網站與 GitHub Repository 均已公開，原典、課程檔案與提交紀錄皆可被他人閱讀。各課的個人筆記只儲存在你使用的瀏覽器，不會上傳到 GitHub；清除網站資料可能使筆記遺失。請勿提交機密資訊至 Repository。
